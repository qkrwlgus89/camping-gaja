# 캠핑가자 v1.1.0 검증 기록

검증일: 2026-11-18 KST. 기존 저장소는 최초 작업 시 비어 있었으며 Next.js App Router + TypeScript + React Three Fiber/Three.js로 구성했습니다. 사용자의 후속 지시에 따라 비공개 2인 구상에서 공동 캠핑장·4인 텐트로 변경했습니다.

## 자동 검사와 대체 환경

- Node.js 24.14.1, macOS, 설치된 Chrome 157.0.8103.79, Playwright 1.65.1.
- 프로덕션 검사는 `NEXT_PUBLIC_ENABLE_SCENE_LAB=true npm run build` 후 `ENABLE_LOCAL_DEMO=true npm start -- --port 3001`에서 수행.
- 게스트 세션 2개는 쿠키/localStorage가 분리된 BrowserContext를 사용. PC 한쪽은 WebGL, 초대받은 모바일 한쪽은 스틸 모드로 실시간 상태를 검증. 별도 모바일 시나리오는 WebGL + 실제 CDP 터치 이벤트 사용.
- 모바일 대체 환경: Chrome 터치 에뮬레이션, 세로 360×800 / 가로 800×360, DPR 2. SwiftShader 소프트웨어 WebGL. 휴대폰 GPU나 Safari 실기기 검증이 아님.
- SQL 검사는 localhost PostgreSQL 18에 폐기 가능한 테스트 DB를 만들고 두 마이그레이션을 실제 적용. Supabase auth/realtime 함수·역할은 최소 stub. 실제 GoTrue/WebSocket 서비스를 실행한 것은 아님.

## 성능과 남은 확인

[성능 샘플](performance.json)은 실제 측정 환경·네트워크·DPR·FCP·리소스 전송량·렌더 FPS를 함께 기록합니다. 이번 샘플은 FCP 1.968초, 전송 2,828,847바이트, 걷기 29.2 FPS, 자동 DPR 0.55였습니다. 30 FPS 목표에는 0.8 FPS 미달하여 성능 목표를 완전 통과로 표기하지 않습니다. 단일 소프트웨어 렌더러 샘플이므로 휴대폰 GPU의 FPS나 첫 진입 3초를 보장하는 근거로 쓰지 않습니다. 느린 기기는 DPR을 단계적으로 낮춥니다.

현재 기본 8개 텐트, 추가 점유 텐트를 포함한 최대 24개 텐트와 32개 상대 아바타 표시를 사용합니다. 여러 광장으로 나누는 운영, 실제 WebSocket 동시 접속 부하, Safari 실기기, 실서비스 기상청 장애, 배포 계정 설정을 공개 전에 확인해야 합니다. 그래픽은 경량 절차적 장면이며 사진 수준의 상용 게임 그래픽으로 검증한 결과가 아닙니다.
